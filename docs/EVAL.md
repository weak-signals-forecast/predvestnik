# Оценка: как мы знаем, что классификатор и ранжировщик хорошие

Три независимые проверки, ни одна не использует мнение языковой модели.

## 1. Экспертная модель: разметка «сигнал или нет»

1 026 записей базы и пула, размеченных командой (127 сигналов, 899 не сигналов), повторённая 5×5 кросс-валидация.
Признаки — только измерения корпуса (наука, бизнес-слои, форма названия), без названий технологий.

| Модель | Без осей, ROC AUC | С осями, ROC AUC | PR AUC с осями |
|---|---|---|---|
| Градиентный бустинг (в сервисе, ради точного SHAP) | 0,783 ± 0,045 | 0,792 ± 0,047 | 0,426 |
| Логистическая регрессия | 0,795 ± 0,043 | **0,820 ± 0,043** | 0,459 |

Оси (`registry/axes.py`) дают прирост обеим моделям. Честно: с осями линейная модель сильнее бустинга;
бустинг оставлен за точное разложение балла по признакам (TreeExplainer). Команда: `python -m registry.expert_model --axes`.

## 2. Историческая модель: метка из будущего, без разметки

Срез 2021 года: 28 568 кандидатов реестра с признаками только по данным до конца 2021; метка — взлетела ли тема
к 2024–2026 (доля работ arXiv втрое выше и ≥ 30 работ; правило зафиксировано до замера). Кросс-валидация 5×.

| Признаки | ROC AUC на срезе 2021 | ROC AUC на экспертной разметке 2026 | Топ-30 среза: взлетели / улучшений известного |
|---|---|---|---|
| 14 базовых | 0,691 | 0,735 | 33 % / — |
| 14 + 10 осей | **0,715** | **0,745** | 37 % / 7 % |

Доля взлетевших среди всех кандидатов 5,1 %, то есть топ-30 с осями угадывает в 7 раз чаще случайного.
Вариант метки «малое, новое и выросшее» (`--label v2`) даёт 0 % улучшений известного в топ-30, но хуже согласуется
с экспертной разметкой (0,614); оставлен как опция, в сервисе — v1 с осями. Команда: `python -m registry.history_model --axes`.

## 3. Ось «родитель» отдельно: предсказывает ли она взлёт

На том же срезе 2021 кандидаты с зрелым лексическим родителем (появился ≤ 2017, ≥ 200 работ в окне, на порядок
объёмнее кандидата) взлетают реже:

| Группа | Взлетели к 2024–2026 |
|---|---|
| топ-100 по баллу, без зрелого родителя | 16,9 % |
| топ-100 по баллу, с зрелым родителем | 4,9 % |
| топ-500, без / с | 13,1 % / 8,0 % |

Примеры взлетевших без родителя: neural radiance fields, deepfake detection, backdoor attacks, self distillation.
Взлетевших с родителем (улучшения известного): explainable artificial intelligence, supervised contrastive learning,
privacy preserving federated learning. Скрипт: `инструменты/анализ/parent_axis.py` (в репозитории — `registry/axes.py`).

## 4. Отложенные запросы (ручная оценка ТОП-10)

18 узких запросов вне шести областей ТЗ (`проверки/злые_запросы.csv`): многослойный графен, натрий-ионные батареи,
квантовые сенсоры, перовскитные элементы, биопечать, нейроморфные чипы, фотонные вычисления, термоядерные материалы,
спинтроника, белковый дизайн, водородные хранилища, мемристоры, твердотельные электролиты, микрофлюидика,
малые модульные реакторы, синтетическая биология, радиофотоника, метаматериалы. Запросы записаны до правок.

Протокол: `python scripts/eval_queries.py --queries … --out …`, эксперт ставит verdict по каждой строке ТОП-10:
S — слабый сигнал по теме, I — улучшение известного, M — зрелое, P — стандарт/протокол, X — не по теме.
Метрики: precision@10 = доля S; доли I, M, P, X.

| Замер | База | precision@10 | Примечание |
|---|---|---|---|
| до (18.10) | v3, 1000 записей, ИИ и финтех | 0/18 запросов с релевантным ТОП-3 | тем в базе нет; область определяется неверно у 13 из 18 |
| после-1 (18.10) | v3 + порядок и фильтры v2 | то же | ранжирование не создаёт знаний, которых нет в базе |
| после-2 | v5 (расширенный корпус: cond-mat, материалы, энергетика, биотех) | — | заполняется после пересборки |

## 5. Демо-запросы: v1 против v2 порядка

18 демонстрационных запросов по шести областям ТЗ, ответы из кэша проверки YandexGPT. С порядком v2 в среднем
9,6 из 15 позиций совпадают с v1; исключены как стандарты Ultra Ethernet, UCIe, A2A protocol; четыре варианта
KV-cache сведены в одну строку с подсигналами. Протокол: `проверки/2026-10-18_демо_v1_vs_v2.txt`.

## Что в этих цифрах не измерено

Качество ТОП-15 на запросах жюри по новым областям до пересборки реестра; калибровка балла как вероятности;
семантическая отличимость кандидата от родителя (считается на сервере по векторам документов, `doc_axes.parquet`).
