# legacy — исследовательский прототип первой версии

Здесь лежит первая версия проекта (сентябрь 2026): корпус OpenAlex по газовым направлениям, кластеризация
эмбеддингов (UMAP + HDBSCAN), лексический детектор всплеска терминов, прогноз на 2029–2031 и HTML-дашборд.

**В рабочем сервисе этот код не используется.** Он оставлен как история метода: именно здесь документный
детектор «работ без предшественников» впервые поймал спутниковый мониторинг метана, который частотный
детектор пропустил (см. `docs/WHY_IT_WORKS.md`). Эта идея вернулась в текущую версию как признак фразы
(`инструменты/сервер/predecessors.py` и ось `doc_novelty` в `registry/axes.py`).

Состав: `src/` — код прототипа, `data/` — его выходы (кластеры, прогноз, сигналы), `requirements.txt` —
его зависимости (UMAP, HDBSCAN, BigQuery), `SETUP_BIGQUERY.md` — патентный слой через BigQuery.
Запуск: цели `ingest`, `embed`, `cluster`, `terms`, `signals`, `stabilize`, `backtest`, `forecast`, `dashboard`
в `Makefile` (пути уже указывают сюда).

Тесты прототипа: `python -m pytest -q legacy/tests` (в CI не запускаются).
